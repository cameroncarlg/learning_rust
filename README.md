# learning_rust

This repository is my personal playground for learning Rust.  
I’m going through *The Rust Programming Language* book and experimenting with exercises and small projects.  

Here you’ll find examples covering:  
- Rust basics (variables, functions, data types)  
- Ownership, borrowing, and lifetimes  
- Structs, enums, pattern matching  
- Small CLI programs and exercises  

The goal is to build understanding through hands-on practice and gradually tackle more complex Rust concepts.
